This platform integrates external software and pretrained
models, including:

| Software | Purpose | Upstream repository |
|---|---|---|
| REINVENT4 | Molecular generation | https://github.com/MolecularAI/REINVENT4 |
| RDKit | Cheminformatics | https://github.com/rdkit/rdkit |
| SCScore | Synthetic complexity | https://github.com/connorcoley/scscore |
| ADMET-AI | ADMET prediction | https://github.com/swansonk14/admet_ai |
| prop-profiler | Molecular property prediction | https://pypi.org/project/prop-profiler/ |
| PyTorch | Deep learning | https://github.com/pytorch/pytorch |
| PyTorch Geometric | Graph neural networks | https://github.com/pyg-team/pytorch_geometric |
