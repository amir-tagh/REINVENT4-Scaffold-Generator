# Historical Implementations

This directory preserves earlier development versions
of the REINVENT4 Scaffold Generator.

| Directory | Contents |
|---|---|
| generation/ | Historical molecular generation workflows |
| analysis/ | Earlier molecular library analysis modules |
| hpc/ | Institution-specific computational launchers |
| patches/ | Historical integration patches |
| root/ | Archived implementations from earlier repository layouts |

These files are retained for historical reference and
development traceability.

They may contain outdated paths, environment settings,
dependencies and interfaces.

They are not maintained as supported V6 entry points.

For current execution, use:

    scripts/run_reinvent_v6.sh

See the current installation guide:

    docs/INSTALLATION.md
